# Code of Conduct

DuxKit AI should be a focused, respectful place to discuss Angular AI UI primitives.

## Expected Behavior

- Be direct and respectful.
- Assume technical disagreement is normal.
- Keep issues and PRs focused on the project.
- Give enough context for others to reproduce or evaluate a problem.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Sexualized language or imagery.
- Publishing private information without consent.
- Repeated off-topic comments, spam, or bad-faith participation.

## Enforcement

The maintainer may edit, hide, or remove comments; close issues or PRs; or block participants when behavior harms the project. Enforcement decisions are made to protect the project and its contributors.

If you need to report conduct concerns, use a private GitHub contact path when available. If no private path is available, open a minimal public issue asking for a private contact and do not include sensitive details.
